# 论文解读：Optical angular momentum derivation and evolution from vectorial field superposition

**作者**：Liang Fang, Jian Wang（华中科技大学武汉光电国家实验室）
**发表**：Optics Express, Vol. 25, No. 19, pp. 23364–23375 (2017)
**DOI**：[10.1364/OE.25.023364](https://doi.org/10.1364/OE.25.023364)

---

## 一、论文核心思想

这篇论文的核心观点是：**光的内禀角动量可以看作矢量光场空间错位（spatial dislocation）的产物**——通过电场矢量在空间中的自旋（spinning，对应SAM）和螺旋（spiraling，对应OAM）来理解角动量的起源。

论文采用**全矢量公式推导**，超越了常用的傍轴近似，系统研究了任意叠加矢量光场中所有角动量分量，包括：

- 纵向和横向的**自旋角动量（SAM）**
- 纵向和横向的**轨道角动量（OAM）**
- SAM与OAM之间的**自旋-轨道转化/偏移（spin-orbit shift）**

## 二、重点解读：图二（Figure 2）

### 图二的内容

图二展示了不同矢量模式及其正交叠加态的**自旋流轨迹（spin flow trajectories）**和空间相位分布：

| 子图 | 模式           | 自旋流特征                                       |
| ---- | -------------- | ------------------------------------------------ |
| (a)  | TM₀₁ 模式      | 闭环自旋流，因纵电场 Ez 的存在而产生横向 SAM     |
| (b)  | TE₀₁ 模式      | 无横向 SAM，因为 TE₀₁ 没有纵向电场分量 Ez=0      |
| (c)  | ψ₁₁(+π/2, π/4) | **右旋螺旋**自旋流，螺旋方向与传播方向（+k）一致 |
| (d)  | ψ₁₁(−π/2, π/4) | **左旋螺旋**自旋流，螺旋方向与传播方向（+k）相反 |
| (e)  | ψ₂₁(+π/2, π/4) | **右旋螺旋**，螺旋瓣数为 2（等于方位角阶数 m=2） |
| (f)  | ψ₂₁(−π/2, π/4) | **左旋螺旋**，螺旋瓣数为 2                       |

### 图二的物理含义

1. **自旋流是多-fold螺旋轨迹**：正交叠加场 ψ_mn(±π/2, π/4) 的总自旋流（纵向 SAM + 横向 SAM 的矢量和）呈螺旋线形态。螺旋的**瓣数等于矢量场的方位角阶数 m**——即 m=1 时为单螺旋，m=2 时为双螺旋。

2. **横向 SAM 与自旋-动量锁定**：在所有情况中，横向 SAM 的方向始终保持不变（锁定于光的传播方向 k），不随叠加参数 Δφ 的符号而改变。这是横向 SAM 的**自旋-动量锁定**（spin-momentum locking）内禀属性。

3. **螺旋手性与 Δφ 的关系**：
   - Δφ = +π/2（即 φ₂−φ₁ = +π/2）→ 右旋螺旋，SAM 与 k 同向
   - Δφ = −π/2 → 左旋螺旋，SAM 与 k 反向
   - 手性由两个矢量场之间的空间取向错位决定（即"偏振手性"）

4. **TM₀₁ vs TE₀₁ 的对比意义**：TM₀₁ 有 Ez 分量→有横向 SAM→自旋流形成空间闭环。TE₀₁ 无 Ez→无横向 SAM→自旋流退化为纯纵向。这直接说明了**纵向电场是横向 SAM 的必要条件**。

## 三、携带轨道角动量的光是如何分解的

### 3.1 核心叠加方案（公式 5-6）

论文提出的分解方案是：任意矢量光场可以表示为**两个方位角依赖的矢量场以 π/2 相位差的相干叠加**：

\[
\psi*{mn}(\varphi_1, \varphi_2, \gamma) = \left[\cos\gamma \cdot V*{mn}(\varphi*1) + i\sin\gamma \cdot V*{mn}(\varphi_2)\right] e^{i(\omega t + kz)}
\]

其中基矢量为：

\[
V*{mn}(\varphi_k) = E_r \cos(m\phi - \varphi_k) \cdot \mathbf{e}\_r + E*\phi \sin(m\phi - \varphi*k) \cdot \mathbf{e}*\phi + iE_z \cos(m\phi - \varphi_k) \cdot \mathbf{e}\_z
\]

**参数含义**：

- **m**：模式阶数/缠绕数（winding number），决定OAM的基本量级
- **φ₁, φ₂**：两个矢量场的初始方位角取向，其差 Δφ = φ₂−φ₁ 决定了空间错位
- **γ**（0≤γ≤π/2）：能量分配系数，在 cosγ 和 sinγ 之间分配归一化能量给两个分量
- **i 因子（π/2 相位差）**：是产生 SAM 和 OAM 的关键

### 3.2 角动量的分解公式

将叠加场代入全矢量角动量公式后，得到：

**纵向 SAM 密度**（公式 8）：
\[
S*z = -\frac{\varepsilon_0}{2\omega} \sin 2\gamma \cdot \sin\Delta\varphi \cdot E_r E*\phi
\]

**纵向 OAM 密度**（公式 7）：
\[
L*z = \frac{\varepsilon_0}{4\omega} \sin 2\gamma \cdot \sin\Delta\varphi \cdot [m(E_r^2 + E*\phi^2 + E*z^2) + 2E_r E*\phi]
\]

**平均 OAM 值**（公式 12）：
\[
\frac{n_i^2 L_z}{W} = \frac{1}{\omega} \sin 2\gamma \cdot \sin\Delta\varphi \cdot [m + \xi(1 - \xi)]
\]

其中 ξ 是**自旋-轨道偏移量**（公式 13），表征了纵向 SAM 向 OAM 的转化程度。

### 3.3 三维 Cartesian 投影分解（公式 18-21）

叠加态可以在 Cartesian 坐标系中投影为三个分量：

```
ψ¹₂₁ = cosγ · cosΔφ · ψ₂₁   → 对应 HE^even 模式
ψ²₂₁ = cosγ · sinΔφ · ψ₂₁   → 对应 HE^odd 模式
ψ³₂₁ = sinγ · ψ₂₁           → 对应 iHE^odd 模式
```

满足归一化条件：**|ψ¹|² + |ψ²|² + |ψ³|² = |ψ|²**

这三个投影分量构成了一个**单位半球面上的态空间**（如图一所示），半球面上的每个点对应一个特定的叠加态，色图表示该态携带的平均 OAM 值。

### 3.4 OAM 产生的本质条件

从公式可见，**OAM ≠ 0 的条件是**：

1. **sin2γ ≠ 0**：即 γ ≠ 0 且 γ ≠ π/2，意味着两个矢量场都参与叠加（不能只有一个）
2. **sinΔφ ≠ 0**：即 Δφ ≠ 0 且 Δφ ≠ π，意味着两个矢量场必须有空间取向错位

当满足以上两个条件时，叠加场同时携带**连续可调的非整数 SAM 和 OAM**。

### 3.5 特殊情形

- **正交叠加（Δφ = ±π/2, γ = π/4）**：HE_m1 模式产生 OAM = ±(m−1)，SAM = ±1；EH_m1 模式产生 OAM = ±(m+1)，SAM = ±1
- **TM₀₁ ± i·TE₀₁（m=0 特例）**：OAM = ±1，SAM = ±1
- **弱导光纤近似（Ez→0）**：ξ→0，自旋-轨道偏移消失，OAM 和 SAM 退化为整数

### 3.6 分解观点的核心洞见

与传统观点（将 OAM 归因于螺旋相位 exp(imφ)）不同，Fang 和 Wang 的分解揭示了：

> **OAM 的本质来源是两个矢量场之间的空间取向错位（Δφ）以及能量不对称分配（γ），而不是单纯的螺旋相位波前。**

这种分解将 OAM 的起源从标量相位推广到了**矢量场的空间构型**层面，统一了 SAM 和 OAM 的描述语言。

## 四、该分解观点的相关文献溯源

这种"将携带 OAM 的光分解为矢量模式叠加"的观点在 Fang & Wang (2017) 之前已有若干重要前驱工作：

### 4.1 光纤矢量模式叠加理论

| 文献                                                  | 贡献                                                                                                                        |
| ----------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Darshti et al., JETP 80, 817 (1995)**               | 首次提出光纤中孤立波前位错的矢量模式叠加形成机制——光纤导模携带的 SAM 和 OAM 可以归因于两个奇偶矢量本征模以 π/2 相位差的叠加 |
| **Dashti et al., Phys. Rev. Lett. 96, 043604 (2006)** | 实验观察到光纤中声学涡旋与光学涡旋之间的 OAM 转移                                                                           |
| **Ramachandran et al., Nanophotonics 2, 455 (2013)**  | 系统总结了光纤中光学涡旋的产生与矢量模式叠加的关系                                                                          |

这是最接近 Fang & Wang 工作的前驱——**Darshti (1995)** 已经意识到光纤导模的 SAM 和 OAM 来自 TE₀₁/TM₀₁/HE/EH 等矢量本征模的叠加，只是当时限制在弱导光纤条件下（Ez≈0），没有涉及非傍轴下的 spin-orbit shift。

### 4.2 Higher-Order Poincaré Sphere (HOPS)

| 文献                                                       | 贡献                                                                                                                                                                      |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- | -------------------------------------------------------- |
| **Milione et al., Phys. Rev. Lett. 107, 053601 (2011)**    | 提出高阶庞加莱球（HOPS）表示，将标准庞加莱球（描述偏振/SAM）推广到包含 OAM 的高阶态空间。高阶庞加莱球的两个极点是一对 OAM 本征态（                                        | L⟩LG⁺ˡ 和 | R⟩LG⁻ˡ），赤道上的点对应矢量涡旋光束（径向、角向偏振等） |
| **Beckley, Brown & Alonso, Opt. Express 18, 10777 (2010)** | 提出"全庞加莱光束"（Full Poincaré beams），通过共轴叠加 LG₀ℓ｜R⟩ + LG₀₀｜L⟩（一个携带 OAM 的拉盖尔-高斯模与基模高斯模的正交圆偏振叠加），在横截面上实现完整的庞加莱球覆盖 |

**与 Fang & Wang 的关键区别**：

- HOPS 使用**两个 OAM 本征模（携带相反 SAM）**作为基矢，且仅有一个方位角取向自由度
- Fang & Wang 使用**两个矢量模式**作为基矢，两者各自有独立的方位角取向（φ₁, φ₂），增加了一个自由度
- 当约束 Δφ = ±π/2 时，Fang & Wang 的表示可等价于 HOPS 描述

### 4.3 Allen 等人的开创性工作

| 文献                                                     | 贡献                                                                                                      |
| -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **Allen et al., Phys. Rev. A 45, 8185 (1992)**           | 建立了拉盖尔-高斯（LG）模式与 OAM 的关系：每个光子携带 ℓℏ 的 OAM。这是将光场分解为 OAM 本征模的奠基性工作 |
| **Padgett, Courtial & Allen, Phys. Today 57, 35 (2004)** | 综述了 OAM 的物理起源和应用                                                                               |

Allen 的分解是将**标量光束分解为 LG 本征模 exp(iℓφ)**，而 Fang & Wang 的分解是将**矢量光束分解为矢量本征模**——前者是标量 OAM 分解，后者是全矢量分解。

## 五、总结

Fang & Wang (2017) 的工作在以下方面做出了独特贡献：

1. **统一的矢量叠加框架**：将 OAM、SAM、spin-orbit shift、横向 SAM 全部纳入"两个矢量场叠加"的统一描述中，用参数 (Δφ, γ) 即可遍历所有可能的角动量态。

2. **超越 HOPS 的自由度**：相比 Milione 等人 (2011) 的高阶庞加莱球（仅有一个方位角自由度），Fang & Wang 的方案引入了第二个独立的方位角取向参数，使得态空间从球面扩展为半球体（或上半球面），能够描述更一般化的偏振椭圆分布不对称性。

3. **明确的物理图像**：图二以直观的自旋流螺旋轨迹展示了正交叠加态的 SAM 构型——纵向 SAM 和横向 SAM 共同编织成多-fold 螺旋，螺旋瓣数等于方位角阶数，手性由 Δφ 决定。这种可视化直接揭示了"矢量场的空间错位产生角动量"的核心思想。

4. **非傍轴推广**：在非傍轴条件下（Ez 不可忽略），spin-orbit shift（ξ ≠ 0）变得显著，导致 OAM 和 SAM 的纠缠和连续取值。这为高折射率差波导（如空心环芯光纤）中的角动量调控提供了理论基础。
